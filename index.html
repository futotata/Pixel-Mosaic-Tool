5. 表示維持・ウィンドウ

OFF

※WebブラウザおよびPWAのセキュリティ仕様上、OSレベルの「常に最前面表示（Always on Top）」は実現できません。代わりに、作業中の画面自動スリープを防ぐ Wake Lock API と、作業用に配置しやすい別ウィンドウ起動ボタンを提供しています。

⚠️ 重要: 保存前に必ずご確認ください

  • モザイクは不可逆です: ピクセル領域を平均色で完全に塗りつぶすため、保存後の画像から元のピクセル情報を復元することはできません。
  • 保存前の目視確認: モザイクサイズが小さすぎると文字や顔立ちが推測される恐れがあります。保存前にズームして十分な強度か必ず確認してください。
  • 元画像の保護: 保存時は 元ファイル名_mosaic.拡張子 として出力され、元の画像ファイル自体は上書きされません。
