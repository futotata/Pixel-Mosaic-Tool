# Pixel Mosaic Tool (ピクセルモザイク編集PWA)

フレームワークを一切使用せず、Vanilla HTML / CSS / JavaScript のみで構築された単一完結型の画像モザイク編集 PWA（Progressive Web App）です。  
ビルド工程不要で、静的ファイルとしてそのまま配信・インストールしてオフラインでも利用できます。すべての画像処理はブラウザ内（ローカル）で完結し、外部サーバーに画像データが送信されることはありません。

## 🚀 起動方法 (ビルド不要)

本アプリはビルド不要です。Service Worker や PWA インストール機能を有効にするため、任意のローカル静的 HTTP サーバーで配信してブラウザで開いてください。

### 方法 1: Python 標準 HTTP サーバー (推奨)
```bash
python3 -m http.server 8080
```
起動後、ブラウザで `http://localhost:8080` にアクセスしてください。

### 方法 2: Node.js (`npx serve`)
```bash
npx serve . -l 8080
```

### 方法 3: VS Code Live Server
VS Code の拡張機能「Live Server」で `index.html` を右クリックし、「Open with Live Server」を選択してください。

## 📲 PWA インストール方法

### 一番かんたん: インストール専用画面から (Android推奨)
HTTPSで配信した状態で `install.html` を Android の Chrome で開き、大きな **「⬇ Androidにインストール」** ボタンを1回タップするだけで、インストール確認ダイアログが表示されます。インストール後は同じ画面が「アプリを開く」に切り替わります。ダイアログを表示できない環境 (アプリ内ブラウザ等) では、画面内に手動手順が自動表示されます。

### 通常のインストール

1. `http://localhost:8080`（または HTTPS 配信環境）に Chrome / Edge などのブラウザでアクセスします。
2. 画面左上の **「PWAインストール」** ボタン、またはブラウザのアドレスバー右端にある「インストール」アイコンをクリックします。
3. 確認ダイアログで「インストール」を選択すると、独立したデスクトップアプリ／ホーム画面アプリとして起動でき、以降はオフライン環境でも動作します。

## 🎨 使い方

### 1. 画像を読み込む
- **ドラッグ＆ドロップ**: PNG / JPG / WebP 画像を画面右側のキャンバス領域にドロップします。
- **ファイル選択**: 左パネルの **「📂 画像を開く (`Ctrl+O`)」** ボタンから画像を選択します。
- **サンプル画像で試す**: 手元に画像がない場合でも、**「サンプル」** ボタンを押すことで 1280×800px のデモ画像を即座に生成して試すことができます。

### 2. 推奨モザイクサイズを確認・適用する
- 画像を読み込むと、画像の**長辺サイズ**と**推奨モザイクサイズ**が常時表示されます。
  - 算出式: 長辺が 400px 以上なら `推奨 = ceil(長辺 / 100)`、最小 `4px`
  - 例: 長辺 `1920px` → `20px`、長辺 `1280px` → `13px`、長辺 `400px` → `4px`
- **「✨ 推奨値をモザイクサイズに適用」** ボタンを押すと、推奨値がワンクリックでモザイクサイズに反映されます。
- モザイクサイズはスライダーまたは数値入力（`1`〜`200px`、`1px` 単位）でいつでも自由に変更できます。

### 3. モザイクを適用する (複数箇所に連続適用可能)
本アプリのモザイクは、対象領域をモザイクサイズのグリッドに分割し、**各セル内の全ピクセルの平均色 (RGBA) を算出して塗りつぶす本格ピクセルモザイク**です。

- **🖌️ ブラシツール (`B`)**
  - ブラシサイズ（円形直径 `4`〜`400px`）を調整し、キャンバス上をドラッグしてなぞった箇所のグリッドセルにモザイクを適用します。
  - カーソル位置には現在のブラシ直径を示す円形プレビューが表示されます。
- **⬚ 矩形選択ツール (`R`)**
  - キャンバス上をドラッグして矩形範囲を選択します。
  - **リアルタイムプレビュー**: 選択中（未確定状態）に左パネルのモザイクサイズを変更すると、選択範囲内のモザイクプレビューがリアルタイムに更新されます。
  - 選択枠内をドラッグして移動したり、四隅・上下左右のハンドルをドラッグしてサイズを微調整することも可能です。
  - **確定方法**: 以下のいずれかでモザイクが本適用されます。
    1. **「✓ 確定適用」ボタン**（左パネルまたはキャンバス上部フローティングバー）をクリック
    2. キャンバス上を**ダブルクリック**
    3. キーボードの **`Enter` キー**を押下
  - **選択解除**: **「解除」ボタン**または **`Esc` キー**で適用せずに選択を解除します。

### 4. 履歴操作 (Undo / Redo)・原画比較・保存
- **元に戻す / やり直す**: 最大 **35段階**（仕様の最低20段階・上限30以上をクリア）まで Undo / Redo が可能です。
- **原画と比較 (Before / After)**:
  - **`H` キーを押している間**、または左パネルの **「👁️ 押下中は原画」** ボタンを押している間、モザイク適用前の原画が表示されます。
  - **「原画固定: ON/OFF」** ボタンでトグル表示することもできます。
- **画像の保存 (`Ctrl+S`)**:
  - **「💾 画像を保存 (`_mosaic`)」** ボタンを押すと、元の画像形式（PNG / JPEG / WebP）を維持したまま **`元ファイル名_mosaic.拡張子`** として保存されます（JPEG は品質 `0.92` で出力）。

### 5. 画面を常に表示 (Wake Lock)・別ウィンドウ表示・ショートカット説明の切替
- Web / PWA のセキュリティ仕様上、OS レベルの「常に最前面表示（Always on Top）」は実現できません。
- 代わりに、作業中の画面自動スリープを防止する **「画面を常に表示 (Wake Lock API)」** トグルと、作業用にコンパクトな独立ウィンドウとして配置できる **「🗗 別ウィンドウで開く」** ボタンを搭載しています。
- **ショートカット説明の表示切替**: 画面をすっきり保つため、ショートカットキーの説明（下部フッター・開始画面内一覧・各ボタン内のキーヒント）は**デフォルトで非表示**になっています。左ツールパネル内の **「⌨ ショートカット説明」** トグルボタンを押すことで、いつでも表示／非表示を切り替えられます（非表示の状態でもショートカットキー自体の動作は有効です）。
- **タッチ操作（ピンチズーム）**: スマートフォンやタブレットなどのタッチ画面では、キャンバス上で**2本指ピンチによる拡大・縮小（0.1倍〜8.0倍）**および**2本指ドラッグによるパン移動**が可能です。1本指タッチ中に2本目の指が触れた場合は描画を安全に中断してピンチへ移行し、全ての指が離れるまで誤描画を防止します。

## 🖼️ アイコンの再生成手順 (フォールバック手順)

`icons/icon-192.png` および `icons/icon-512.png` はすでに Python 標準ライブラリを用いて生成・同梱されています。  
万が一 PNG アイコンを再生成したい場合や、`icons/icon.svg` から変換したい場合は、以下のいずれかの手順で生成できます。

1. **ImageMagick / Inkscape / rsvg-convert を使う場合 (`icons/icon.svg` から変換)**:
   ```bash
   rsvg-convert -w 192 -h 192 icons/icon.svg -o icons/icon-192.png
   rsvg-convert -w 512 -h 512 icons/icon.svg -o icons/icon-512.png
   ```
2. **外部パッケージ不要の Python 標準ライブラリ (`zlib`, `struct`) で生成する場合**:
   Python 3 があれば追加ライブラリなしで直接 PNG を出力できます（生成済みファイルと同一です）。
